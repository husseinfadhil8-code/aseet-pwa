# التحقق وحدود المراجعة

الفرع `feat/waseet-marketplace-experience` مبني على PR #7 عند dc9aa78، الذي يتضمن PR #6. طلب المراجعة الجديد موجّه لفرع PR #7 لعرض تغييرات التجربة وحدها. لا دمج في main ولا نشر.

## التحقق المحلي

- 16 اختبار migrations حقيقية عبر Supabase CLI وPostgreSQL معزول، بما فيها خصوصية المالك، منع اقتحام محادثة أخرى، ومنع العضو المحظور من القراءة والإرسال.
- 44 اختبار RLS ومبيعات وعمولات وتراجع وتزامن.
- 9 اختبارات لآلية تطبيق دفعة migrations وسجل البصمات دون أي عميل مستضاف.
- 25 اختبار وحدة/استيراد/أمان الوجهة وHTML وJavaScript وmanifest وحدود التخزين المؤقت.
- 15 اختبار Chromium لأمان الأحداث والصور والمبيعات وحماية الطلب المكرر.
- 19 اختبار Chromium للدخول والانضمام وتأكيد البريد والاستعادة والرسائل والفلاتر والتكبير والتحجيم وRTL. شاشات 320، 375، 390 و430 بكسل.
- مجموع الاختبارات المحلية: 128. فحص JavaScript وgit diff --check ضمن التحقق.

اختبارات المتصفح تحجب الاتصالات الخارجية بالكامل وتستخدم responses مصطنعة. اختبارات SQL تستخدم قواعد قابلة للإزالة داخل حاويات Docker بلا شبكة؛ لا تحمل بيانات أو كلمات مرور حقيقية. أعطال الاختبارات المكتشفة (مسار الاستفسارات، محاكاة scroll الناعم، اختلاف manifest) عولجت قبل إعادة التحقق.

WebKit أُضيف إلى CI (19 اختباراً إضافياً). تعذّر تشغيله محلياً لغياب libgtk-4 وملحقاتها، وعدم توفر صلاحية تثبيت اعتماديات النظام. لا يُعد WebKit على CI اختبار iPhone فعلياً.

## القاعدة المستضافة

لم نطبق migration السادسة على Waseet-Test، ولم نتصل بقاعدة الإنتاج. المخطط التجريبي السابق ما زال يحتوي migrations الخمس المعتمدة. محاولة GET لقراءة إعدادات Auth عبر Management API رفضت الوصول؛ لم تُرسل بيانات تسجيل أو بريد أو كلمة مرور. يلزم تفويض قراءة إعدادات Auth الآمن وحساب/بريد اختبار مخصص لاختبار التأكيد والاستعادة الحقيقيين. لا تضع أي رمز أو كلمة مرور في المحادثة أو PR.
