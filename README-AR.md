# وسيط — بداية التطبيق الحقيقي (نسخة تجريبية)

## ماذا تعمل هذه النسخة؟
- واجهة عربية RTL مناسبة للموبايل.
- إضافة أغراض مع السعر والمنطقة والعمولة.
- إضافة مندوبين برمز فريد.
- تسجيل بيع مكتمل وحساب تقسيم العمولة 50/50.
- حفظ البيانات محلياً في المتصفح نفسه.
- ملفات PWA أساسية للتثبيت من Safari/Chrome بعد النشر على رابط HTTPS.

## ما الذي لم يكتمل؟
هذه ليست النسخة النهائية متعددة المستخدمين. لا يوجد تسجيل دخول، ولا قاعدة بيانات مشتركة، ولا صلاحيات مدير/مندوب، ولا رفع صور، ولا إرسال إشعارات. البيانات محلية في المتصفح وقد تضيع إذا مسحت بيانات الموقع. لا تستخدم بيانات شخصية حقيقية في هذه المرحلة.

## نشر مجاني من الآيفون — خيار مقترح
1. افتح github.com في Safari وأنشئ حساباً أو سجّل الدخول.
2. أنشئ مستودعاً جديداً باسم `waseet-pwa` واجعله Public مؤقتاً لسهولة النشر.
3. ارفع جميع الملفات والمجلد `icons` كما هي إلى المستودع. على الهاتف يمكنك استخدام زر Add file ثم Upload files.
4. من إعدادات المستودع افتح Pages، ثم اختر النشر من الفرع `main` والمجلد `/(root)` واحفظ.
5. انتظر ظهور رابط GitHub Pages من قسم Pages وافتحه في Safari.
6. على الآيفون: زر المشاركة في Safari ثم Add to Home Screen (إضافة إلى الشاشة الرئيسية)، ثم Add.
7. اختبر إضافة غرض تجريبي ومندوب وبيع. تذكّر أن هذه البيانات محفوظة في هذا المتصفح فقط.

## أيقونات التطبيق
ملفّات الأيقونات داخل مجلد `icons`. إذا لم تظهر في المجلد عند رفع الملفات، ارفعها أيضاً.

## الخطوة التالية بعد نجاح الاختبار
ربط Supabase أو خدمة مماثلة لتسجيل الدخول وقاعدة بيانات مشتركة، ثم إعداد سياسات أمان حقيقية بحيث لا يرى المندوب بيانات صاحب الغرض أو عمولات غيره. لا تنشر بيانات حقيقية قبل إتمام ذلك.
