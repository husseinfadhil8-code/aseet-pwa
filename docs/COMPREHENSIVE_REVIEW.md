# مراجعة واجهة وسيط — الإصدار 10

الإصدار المرشح `2026-10-25-interface-review-10` مبني على main عند `bcdd1f16192b3ecb0909df7eacc3a83ba22f8288`، مع حفظ أعمال #44 و#47 و#48 و#49. لا يتضمن تغييرات قاعدة بيانات أو migrations أو تفعيل استيراد أو نسخ تلقائي.

## التغيير

- توحيد هيكل RTL والألوان والمسافات والأزرار والأيقونات المتجهية، ونقل التنسيق المتعارض إلى ملفات واضحة. الشعار الأصلي محفوظ، مع أيقونات PNG وmaskable لتثبيت التطبيق.
- رأس مختصر بجرس ذهبي، خمسة تبويبات ثابتة، رئيسية تعرض الخدمات والأغراض الأخيرة، عرض أغراض بشبكة مناسبة للتابلت وفلاتر متقدمة قابلة للطي. أدوات المدير وطلبات أصحاب الأغراض تحت «المزيد».
- صور الحساب والمحادثات دائرية، قص مربع قبل الرفع، بديل آمن عند فشل الصورة، تحديث فوري، وحراسة تبديل الحساب والضغط المتكرر.
- محادثة تستعمل الارتفاع المتاح مع لوحة المفاتيح والمناطق الآمنة، أسماء مرسلين وفتح ملفهم، روابط HTTP(S) آمنة، دعم IME، حفظ المسودات وموضع القراءة، ومنع عرض استجابة حساب سابق.
- إعداد الإشعارات ينتقل إلى الحساب دون إلغاء الاشتراك. لا تظهر نافذة التفعيل قبل اكتمال فحص الاشتراك الموجود، ولا يوجد تفعيل أو إلغاء تلقائي جديد.
- دخول محمي من الضغط المتكرر ورسائل خطأ عربية في مسارات الحساب والإدارة دون تفاصيل SQL أو محتوى استجابات الخدمة. الخروج يمسح حقول كلمات المرور والهوية والمسودات والملخصات الظاهرة.
- مشاركة الغرض تحذف السطور الموسومة باسم المالك وهاتفه والعمولة؛ ليست كشفاً عاماً لكل معلومة شخصية قد تُكتب كنص حر.
- تحديث Service Worker ذري لأصول الإصدار، تشغيل القشرة دون اتصال، وتنبيه تحديث ينتظر موافقة المستخدم قبل إعادة التحميل. بيانات Auth وREST وStorage والرسائل لا تُخزن في cache العامل.

## الاختبارات والحدود

نجح محلياً 48 اختبار وحدة و20 اختبار مراجعة شاملة و24 اختبار توافق إصدار. نجحت أيضاً مجموعات الأمان 10، الدفعة 31، صفحات الأغراض 19، والتقارير 6. اختبارات PostgreSQL المعزولة للمقترح الموجود مسبقاً نجحت: 4 تزامن و19 صلاحيات؛ لم نعد تنفيذ المقترح من الصفر.

المصفوفة تشمل عرض 320 و360 و375 و390 و393 و414 و430 و768، وارتفاعي 568 و844 للتبويبات، وارتفاعات 320 و400 و568 و844 للمحادثة، ومناطق آمنة علوية وسفلية ومحاكاة تقلص viewport. تغطي النوافذ، نهاية القوائم، النصوص الطويلة، فشل الصور، الخروج، الاشتراك، الروابط، الضغط المتكرر، والعمل دون اتصال بعامل خدمة فعلي. CI يفحص Chromium وWebKit؛ لا يُعتبر pending أو cancelled نجاحاً.

ليست هذه تجربة جهاز iPhone أو Android فعلي. لم ننفذ دخولاً أو بيعاً أو دفعاً أو رسائل أو رفع Storage أو تسليم Push أو SMTP حقيقياً على الإنتاج. تأكد HTTP للـAuth العام ورفض قراءة الأغراض المجهولة فقط؛ لا يثبت ذلك صلاحيات الحسابات المسجلة.
