# تشغيل سوق تلغرام

رابط السوق الذي أكد المالك فتحه مباشرة على الآيفون: https://t.me/WaseetIraqMarketBot/market .

## المدير والقناة

اضبط OWNER_TELEGRAM_ID بمعرف المدير الرقمي الصحيح في Worker فقط. لا تُستنتج الإدارة من اسم المستخدم أو أول زائر. أول دخول موثّق لهذا المعرف يربطه كمدير رئيسي وحيد في قاعدة تلغرام؛ تغيير المالك لاحقاً يحتاج إجراءً مراجعاً، وليس تعديل واجهة أو تعيين admin من لوحة المستخدمين. القيم السابقة ADMIN_TELEGRAM_IDS تقبل معرفاً واحداً فقط للتوافق، وتُرفض القوائم المتعددة.

لربط قناة يملكها المدير: اضبط MARKET_CHANNEL_ID باسم @القناة أو معرفها -100… وأضف البوت مديراً بصلاحية نشر الرسائل. النشر صريح من لوحة الإدارة بعد المراجعة، وليس آلياً لكل إعلان. الطلب المتعذر تأكيد تسليمه يثبت في review ولا يعاد تلقائياً لتجنب التكرار. إخفاء الإعلان داخل السوق لا يمحو منشور قناة سابقاً؛ يراجعه المدير في Telegram عند الحاجة. لا نشر لقناة لم يفوضها المالك.

## الباقات والمدفوعات

سعر PROMOTION_STARS السابق يبقى لباقة7 أيام. الباقات الإضافية لا تعمل إلا بإعداد PROMOTION_PACKAGES_JSON في Cloudflare بعد اعتماد المالك للأسعار: مصفوفة عناصر days (1 أو14 أو30) وstars (عدد صحيح موجب). لا تغير باقة7 بهذه المصفوفة. لا أسعار افتراضية ولا تحويل من الدينار. الاختبار المحلي اصطناعي، ولا يعني نجاح دفع حقيقي. نجاح الفاتورة في الواجهة لا يفعّل؛ successful_payment وحده يسجل الدفع ويحدد المدة المحفوظة. الاسترداد غير المؤكد يتوقف للمراجعة.

## النشر التلقائي دون أسرار في GitHub

صلاحية Workers Scripts الحالية تسمح بالنشر، لكن فحص Workers Builds API أعاد403/10000. ربط GitHub عبر Cloudflare يحتاج تفويض المالك لـGitHub App في لوحة Worker ← Settings ← Builds. بعد الربط اختر مستودع husseinfadhil8-code/aseet-pwa والفرع feature/telegram-market-starter، والجذر telegram-market.

- Build command: `npm ci --ignore-scripts && node scripts/cloudflare_build_gate.mjs && npm test`
- Deploy command: `npm run deploy`

بوابة البناء ترفض النشر حتى تنجح اختبارات PostgreSQL وChromium وWebKit لنفس commit على فرع السوق. لا تنشر منmain أو فرع المسودات. المهلة ست دقائق؛ فشل الوصول لـGitHub أو تجاوز حصته يمنع النشر. تبقى الأسرار في Cloudflare؛ لا تنسخها إلى مصدر GitHub أو إعداداته. الربط غير مفعّل ما لم ينجح التفويض الفعلي، وتوثيق هذه الإعدادات لا يعتبر تفعيل النشر الآلي.
