# استعادة بحث السوق — 2026-10-25-search-recovery-5

بعد تغيير الفلاتر وفشل تحميل الصفحة الأولى، كانت النتائج القديمة تُحفظ لكن زر تحميل المزيد قد يختفي أو يرسل مؤشر الصفحة القديم مع الفلاتر الجديدة. أصبحت إعادة المحاولة تبدأ من أول صفحة وتستبدل النتائج فقط عند نجاح القراءة. يبقى الزر متاحاً حتى لو كانت النتيجة السابقة فارغة، وتُهمل الردود المتأخرة بعد مسح الفلاتر أو تبديل الحساب.

أضيف زر «مسح الفلاتر» يمسح البحث والسعر والصنف والمنطقة ويعيد الحالة إلى «المتاح الآن»، ويستخدم مسار البحث المؤجل نفسه دون مزج صفحات البحث السابق. لا تغييرات على استعلامات الصلاحيات أو الأعمدة أو RPC أو قاعدة البيانات أو preview.

تغطي أربعة اختبارات متصفح جديدة فشل البحث وإعادة المحاولة من أول صفحة، وإعادة المحاولة بعد نتيجة فارغة، ومسح الفلاتر أثناء طلب قديم، ومسح حالة إعادة المحاولة عند الخروج. اختبارات المتصفح تستخدم بيانات اصطناعية وطلبات معترضة؛ لا تثبت دخولاً حقيقياً أو تغييراً مستضافاً. يراجع CI Chromium وWebKit قبل الدمج، ثم يُتحقق من Pages والجذر وعلامة الإصدار وبصمات الأصول. الرجوع: revert لمراجعة الواجهة عند الحاجة، دون SQL.

دمج PR #20 كعمل مكتمل ناجح CI. مراجعة بدائل النسخ الرسمية منفصلة في BACKUP_SUPPORTED_PATHS.md؛ لا تُعاد محاولات TCP، ولا تتوقف هذه الدفعة على النسخ أو تغييرات الخادم.
