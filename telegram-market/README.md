# وسيط داخل تلغرام — تجربة أولية
مسار مستقل داخل مستودع وسيط الحالي، بدون تعديل ملفات التطبيق الأصلية.

## ما تم إنجازه
- واجهة عربية RTL مخصصة للهاتف: تصنيفات، بحث، بطاقات، ونموذج إضافة إعلان محلي تجريبي.
- بوت Cloudflare Worker يستقبل /start و /market ويرسل زر فتح السوق.
- مصادقة Telegram Mini App على الخادم عبر فحص توقيع initData وتاريخ المصادقة.
- حماية webhook بواسطة TELEGRAM_WEBHOOK_SECRET.

## تنبيه
هذه نسخة بداية **وليست سوقاً منشوراً**. إعلانات الواجهة تجريبية ومحلية للجهاز، ولا توجد بعد إدارة حقيقية للسلع أو المندوبين أو بوابة دفع. لا تدخل بيانات عملاء حقيقية للاختبار.

## التشغيل
1. أنشئ بوت عبر @BotFather (لا تضع رمزه في GitHub أو المحادثة).
2. انشر `miniapp/index.html` من هذا الفرع على رابط HTTPS (GitHub Pages أو Cloudflare Pages)، واضبط رابط Mini App من BotFather.
3. أنشئ Worker على Cloudflare وانشر الملف `worker.js` فيه، ثم ضع الأسرار عبر Cloudflare: `TELEGRAM_BOT_TOKEN` و `TELEGRAM_WEBHOOK_SECRET`، ومتغير `MINI_APP_URL` (الرابط HTTPS).
4. اربط Telegram webhook على `https://YOUR-WORKER.workers.dev/webhook` باستخدام setWebhook ومعامل secret_token مساويًا للسر المضاف. نفّذ هذه العملية في أداة موثوقة ولا ترسل الرمز إلى الدردشة.
5. اختبر /health و /start وافتح الواجهة من زر البوت.

## المرحلة التالية
- ربط Supabase بطريقة آمنة مع صلاحيات مستقلة للجمهور والمندوبين والمدير؛ تدقيق جداول وسيط الموجودة قبل أي migration.
- تخزين صور الإعلانات ومراجعة النشر والمفضلة والبحث.
- قناة تلغرام تنشر الإعلانات الموافق عليها وتربطها بالسوق.
- تفعيل Telegram Stars للترويج الرقمي بعد التحقق من قواعد الدفع الرسمية؛ لا تعتمد على أسعار أو دفعات غير مؤكدة.

## الأمان
لا تعتمد على initDataUnsafe للهوية أو الدور، ولا تضع service_role أو رمز البوت في الواجهة. هذه النسخة لا تدمج قاعدة الإنتاج ولا تنشر تغييرات عليها.
