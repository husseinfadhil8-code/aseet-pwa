## متابعة خصوصية جهات الاتصال والنسخ

- اختبار owner_phone توسع لرفض القراءة المباشرة والصف الكامل وrow_to_json، ورفض RPC للزائر والمندوب والمدير غير النشط، مع نجاح المدير النشط. السادسة لم تتغير.
- جرد النسخ يختبر catalog وعدّ الصفوف فعلياً داخل PostgreSQL، ويرفض الادعاء برؤية كاملة عند غياب bypass RLS. اختبارات offline تغطي اقتباس أسماء catalog والقيم غير الصالحة وعدم مساواة unknown بالصفر.
- واجهة الاتصال عند الطلب والردود المتأخرة وإخفاء البيانات ونصوص الأخطاء وعدم التخزين اختُبرت في Chromium.
- بروفة custom pg_dump/pg_restore من مصدر محلي اصطناعي إلى قاعدة جديدة بلا شبكة؛ تتم مقارنة ACL الفعلية مع تطبيع منح PostgreSQL الافتراضية، وأدوار السياسات بأسمائها وترتيب ثابت، ثم فحص السادسة وحفظ البيانات. لا GoTrue أو ملفات Storage حقيقية في fixtures.
- الجرد المستضاف للقراءة فقط مستقل عن البروفة: أربع قراءات ناجحة، خمس migrations مطابقة، السادسة معلقة، لا backups أو PITR، وجداول التطبيق وبيانات Auth فارغة وStorage objects صفر. لا تغيير مستضاف.
- WebKit المحلي احتاج مكتبات نظام غير مثبتة؛ التنزيل وحده لم يثبت التشغيل. يعتمد إثبات المحرك الثاني على نتيجة CI للرأس الجديد، ولا يُدعى نجاحه محلياً.
