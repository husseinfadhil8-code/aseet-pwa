# مراجعة واجهة وسيط — PR #61

## النطاق
الفرع `design/premium-mobile-ui-20261029`، بدأ من `83a59ad`. لا دمج في main ولا نشر إنتاج ولا تعديل بيانات أو مخطط أو RLS. المشروع الحالي JavaScript دون إطار، Supabase Auth/REST/Storage، Service Worker، وملفات عرض مشتركة. طبقة التصميم الوحيدة لهذه الدفعة `styles/premium-mobile.css`؛ لم نكرر إضافة ملفات تصحيح CSS جديدة أو نحذف الأنماط القديمة اللازمة للشاشات الثانوية.

## المنفّذ
- نظام ألوان ومسافات وأسطح متسق مبني على المرحلة الأولى، وتصميم RTL للهاتف والتابلت.
- بحث من الرئيسية يستدعي البحث الموجود؛ التصنيفات تستخدم خيارات السوق الفعلية.
- بطاقات سوق بعمودين من 375px، وعمود واحد للشاشات الأصغر، وصور contain دون قص، وأزرار تفاصيل تلتف دون تجاوز العرض.
- استعادة موضع تمرير كل تبويب؛ رفض الانتقال غير المصرح به لا يغيّر الصفحة الحالية.
- تصحيح حساب مؤشر صور RTL باستخدام القيمة المطلقة للتمرير.
- معرض صور fullscreen داخل التطبيق بدلاً من فتح كل صورة في تبويب خارجي، يدعم السحب والإغلاق وعودة التركيز، ومعالجة الصورة المفقودة.
- الحفاظ على التحميل المتدرج الموجود والتقسيم إلى صفحات، دون جلب كل الصور أو المنتجات مسبقاً.
- تحديث إصدار كاش الواجهة مع بقاء التحديث بطلب المستخدم وعدم تخزين بيانات الحسابات والمحادثات.
- إضافة اختبارات التفاعل إلى CI لكل من Chromium وWebKit.

## الوظائف الموجودة والحدود
هذه نسخة PWA لإدارة الأغراض والبيع بالعمولة وليست نسخة Mini App الخاصة بالبوت. إعدادها الحالي يشير إلى Supabase `auqxdtbvfonzrlilygjg`؛ لا يجوز استبداله تلقائياً بقاعدة البوت. الواجهة والكود الحاليان يعتمدان دوري admin وrep؛ لا توجد تجربة متصفح عام مستقلة مكتملة في هذا الفرع. زر الاستكشاف يطلب تسجيل الدخول بالفعل. لم نختلق دور عميل أو صفحات غير موجودة.

الموجود: حسابات، سوق، بحث وفلاتر، صور متعددة، تفاصيل ومشاركة، استفسارات، محادثات، إدارة مندوبين، مبيعات وعمولات ومستحقات وإشعارات. بقاء الوظائف في الكود واختبارها المعزول لا يثبت أن إعداد SMTP أو Push أو سياسات الخادم مفعّلة في الإنتاج.

لم تُعدّل أي سياسة RLS. اختبارات الأدوار تتحقق من حجب الواجهة وتنظيف الحالة والطلبات المعزولة؛ لا تثبت سياسات قاعدة الإنتاج لكل دور. إثبات فصل بيانات الإدارة والعمولات يتطلب اختبار JWT حقيقي لحسابات معتمدة على قاعدة هذا التطبيق، وفحص سياساتها قبل الدمج. لم نستعمل سر قاعدة البوت لاختبار قاعدة مختلفة.

## التحقق
- الاختبارات تستخدم بيانات اصطناعية صريحة وتمنع الطلبات الخارجية؛ لا حسابات أو إعلانات أو مبيعات حقيقية أُنشئت.
- Chromium: التخطيطات من 320 إلى 768px، مساحات آمنة ولوحة مفاتيح محاكاة، المحادثات والنوافذ والأسماء الطويلة، المصادقة والخروج المعزولان، مشاركة دون بيانات خاصة، الأدوار، العمل دون اتصال وكاش الواجهة.
- اختبارات جديدة للبحث، استعادة التمرير، رفض تبويب المدير للمندوب، مؤشر RTL، فتح الصورة الثانية بالحجم الكامل وEscape وعودة نافذة التفاصيل.
- الصور المرفقة أمثلة اختبارية وليست منتجات حقيقية.
- WebKit محلياً لم يبدأ بسبب مكتبات نظام مفقودة؛ لم يُختبر Safari على جهاز آيفون فعلي، ولا فتح تطبيقات المشاركة الأصلية أو لوحة مفاتيح iOS الحقيقية. CI يحتوي اختبارات WebKit مع تثبيت اعتماداته.

نجح محلياً: 49 اختبار Python، و115 تشغيل اختبار متصفح عبر مجموعات security/comprehensive/release/batch/paging/reports/premium (تتضمن المجموعات إعادة استخدام بعض الحالات). فحوص syntax وdiff سليمة.
